# Foresight

**Личный AI-тренер по Dota 2.** Разбирает твои реплеи по эпизодам и судит решения по тому,
что ты **мог знать в моменте**, — а не по исходу матча.

> Hindsight — это «надо было отойти, тебя же убили». Foresight — это «в 33:39 ты видел 1 из 5
> врагов, Pudge пропал 119 секунд, но у тебя был фулл-ХП, и ты зашёл вслепую». Первое бесполезно.
> Второе делает тебя сильнее.

Python 3.12 · 218 тестов зелёные · LLM через подписку (`claude -p`) · пет-проект, не продукт

---

## Философия

Три принципа, вокруг которых построен весь код:

1. **Судим решение, а не результат.** Правильный заход, который не прошёл из-за тиммейта, — это
   правильный заход. Исход (`radiant_win`) физически не доходит до языковой модели — это гарантия
   *by construction*, а не просьба в промпте. Вердикт вполне может быть «норм, вариативно».

2. **Судим из того, что игрок мог знать.** «Как надо было» выводится из информации, доступной
   **в точке решения**: кого видно и кого нет, сколько секунд враг пропал с радара, твои ресурсы,
   тайминги. Не задним числом.

3. **Главная ценность — системные лики по многим матчам, а не ошибки в одном.** Один матч шумный;
   паттерн из 20 матчей — это уже диагноз.

«Как надо было» синтезируется из трёх источников разной надёжности, и уровни не смешиваются:

| Источник | Надёжность | Как подаётся |
|---|---|---|
| Выводимо из данных реплея (last-seen врагов, «4 пропали 20 c») | сильный | как факт |
| Курируемый принцип Доты (`coach/principles.md`) | средний | как ориентир |
| Параметрическое знание модели о Доте | слабый / опасный | **всегда** как гипотеза |

## Что он делает

Три режима, от «обзор всего матча» до «системный разбор серии»:

### 1. Обзор всего матча по эпизодам (главный режим)

```bash
dota-coach analyze --match-id 8961642706 --account-id YOUR_ID --coach \
  --gamerecordings "D:/Steam/userdata/XXYYZZ/gamerecordings" \
  --out review_8961642706
```

Берёт реплей `.dem`, режет матч на **эпизоды** (тимфайты + твои смерти, включая соло + просадки
нетворса) и на каждый отдаёт карточку:

- **тренерский комментарий LLM** — расклад сил рядом, кто был виден/невидим и сколько, зона карты,
  отрыв от команды → ситуация + конкретный вывод;
- **видеоклип 30 секунд** (20 c до / 10 c после), автоматически нарезанный из твоей записи и
  **выровненный по игровым часам в HUD**;
- на 1–2 самых острых эпизода — полный разбор вглубь (`--deep N`, кап 2).

Результат — самодостаточная папка `index.html` + `clips/NN.mp4`.

### 2. Системные лики по серии матчей

```bash
dota-coach coach --account-id YOUR_ID --n 20 --out coach.html
```

Детектор ликов (**ролевой** — пороги зависят от позиции pos1–5) находит главную системную дыру,
LLM формулирует бриф: главный лик → диагноз → почему топит → 1–2 дрилла. Плюс **петля
подотчётности**: метрика лика-фокуса сравнивается между прогонами — это считает код, не модель.

`--dry-run` печатает промпт без вызова LLM (дешёвая итерация).

### 3. Сухие лики без LLM

```bash
dota-coach leaks --account-id YOUR_ID --n 50 --out leaks.html
```

## Как это работает

```
OpenDota API ──┐
 (события,      │
  тайминги,     ├─► фокус/эпизоды ─► info_state ─► LLM (claude -p) ─► HTML + клипы
  бенчмарки)    │    (код)          (что было       (только текст,
.dem реплей ────┘                    знаемо)          без исхода)
 (manta, Go)                                          │
Steam-запись ──────────────────────────────────► видеоклип + кадр
 (DASH-буфер)                                     (выравнивание по HUD-часам)
```

- **Данные матча** — OpenDota по `match_id` (смерти, тимфайты, нетворс, тайминги предметов, варды,
  объекты). Находят *где* и *что* важно.
- **Реплей `.dem`** — скачивается с Valve, распаковывается (zstd), парсится **Go-экстрактором на
  [manta](https://github.com/dotabuff/manta)** в JSONL: позиции всех 10 героев @1 Гц + варды +
  HP/мана/уровни. Даёт *тонкое состояние*, которого нет в OpenDota. Парсер — тупой экстрактор
  (ноль логики), вся аналитика в Python.
- **`info_state_at(parsed, t, slot)`** — информационное состояние в точке решения: вижн кругами
  (аппроксимация, без рельефа/деревьев), last-seen врагов и `missing_for`, ресурсы, расклад сил
  рядом, зона карты. Это и есть «что игрок мог знать».
- **Видео** — опционально. Steam Game Recording пишет скользящий DASH-буфер (`.m4s`-осколки);
  `find_session` + `stitch_window` сшивают окно матча, `read_clock` + `auto_offset` выравнивают
  игровой 0:00 по цифрам HUD-часов (консенсус по нескольким кадрам — устойчив к кривым чтениям).

Реплей-слой строго **опционален**: нет реплея → мягкая деградация до разбора по данным.

## Установка

Нужны **Python 3.12**, **Go ≥ 1.24** (для парсера реплеев) и, по желанию, **Claude Code CLI**
(для LLM в счёт подписки).

```bash
# 1. Python-зависимости (requests, opencv, numpy, zstandard, imageio-ffmpeg, ...)
pip install -e ".[dev]"      # или poetry install

# 2. Go-экстрактор реплеев → replay_tool/replay_tool(.exe)
cd replay_tool && go build && cd ..

# 3. ffmpeg нужен для клипов — ставится автоматом с imageio-ffmpeg (портативный), отдельно не нужен

# 4. (для LLM-разбора) Claude Code CLI, залогиненный подпиской
npm i -g @anthropic-ai/claude-code && claude login
```

Проверка:

```bash
pytest -q          # 218 passed
```

## Провайдер LLM

По умолчанию — **`claude -p`**: вызовы идут через Claude Code CLI **в счёт подписки**, а не за
API-кредиты. Запасной провайдер — любой OpenAI-совместимый эндпоинт (GLM и пр.).

| Провайдер | Как включить | Переменные окружения |
|---|---|---|
| `claude` (по умолчанию) | `--provider claude` | `DOTA_COACH_CLAUDE_BIN` (опц., дефолт `claude`) |
| `openai` / `glm` | `--provider openai` | `DOTA_COACH_LLM_BASE_URL`, `DOTA_COACH_LLM_API_KEY`, `DOTA_COACH_LLM_MODEL` |

Выбор: флаг `--provider` → env `DOTA_COACH_LLM_PROVIDER` → дефолт `claude`.
Цена обзора матча — ~9–15 вызовов `claude -p` (первый прогон несколько минут, дальше кеш).

## Статус и границы

**Готово и влито в `master`:** MVP → ЛЛМ-коуч серии → `claude -p` → ролевые лики → одиночный
фокус-разбор → парсинг реплеев (позиции/вижн/ресурсы) → обзор всего матча по эпизодам с
видеоклипами и тренерскими карточками. Проверено на живых матчах (acc 44365175).

**Осознанные границы v1:**

- Камеры/«куда смотрел» в реплее нет — это дыра, которую закрывает только CV по записи POV
  (будущая фаза). Парсингом не закрыть.
- Туман войны — аппроксимация кругами (без рельефа, деревьев, дня/ночи), помечается как оценка.
- Авто-выравнивание видео работает на 1080p; иначе задай `--video-offset` вручную.
- Combat-log урона и касты способностей пока не эпизоды (смерти и так есть из состояния).

**Дорожная карта:** CV по своей записи за POV (камера-бокс = «куда смотрел», миникарта,
осознанность) → RAG, когда база принципов перерастёт промпт → дата-пайплайн тенденций хай-ммр.
